# Wedding Invitation Template

A luxury, 1:1 responsive digital wedding invitation website built with Vite, React 18, TypeScript, Tailwind CSS, GSAP 3 (ScrollTrigger), and Lenis smooth scrolling.

## Features
- **10 Luxury Sections**: Splash Cover, Hero, Our Love Story with scroll-linked parting clouds, Happy Couple, Wedding Details with circular iris reveal, Order of Events with animated gold spine, Words of Love, RSVP, Countdown & Live Wishes, and Mobile Footer.
- **Motion Engine**: GSAP 3 ScrollTrigger choreography and GPU-composited ambient loops with `prefers-reduced-motion` compliance.
- **Config-Driven**: Zero-code customization via `src/config/weddingConfig.ts`.
- **Responsive**: Fully optimized for mobile (375px) and desktop (1920px).

## Development
```bash
cd web
npm install
npm run dev
```

## Production Build
```bash
cd web
npm run build
```
